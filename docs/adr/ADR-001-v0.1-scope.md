# ADR-001: Alcance de la Versión v0.1 y Punto de Entrada en DashAI

## Estado
Aceptado

## Fecha
2026-10-27

## Contexto
El objetivo del proyecto `dashai-system-one-plugin` es integrar modelos abiertos de "System One" (modelos neuronales compactos y rápidos orientados a decisiones tipadas: choice, score, noul) dentro de la plataforma DashAI.

DashAI organiza sus flujos de trabajo mediante tareas (`Task`), modelos (`Model`), métricas (`Metric`) y cargadores de datos (`DataLoader`). La introducción prematura de una nueva tarea central `SystemOneTask` requeriría modificar el repositorio núcleo `DashAI/dashAI`, comprometiendo la compatibilidad independiente del plugin e incrementando la superficie de fallos.

Por otro lado, los casos de uso más urgentes y directos para modelos como Laya y GLiNER-Decide en producción son la clasificación de textos (enrutamiento de consultas, categorización de intención, triaje de tickets y análisis de sentimiento con opciones discretas).

## Decisión
1. **Punto de entrada inicial (v0.1):** Integrar exclusivamente mediante la tarea estándar `TextClassificationTask` de DashAI.
2. **Modelos en el alcance v0.1:**
   - `convaiinnovations/laya` (LayaRouterTextClassifier)
   - `convaiinnovations/laya-multilingual` (LayaMultilingualRouterTextClassifier)
   - `fastino/GLiNER2.5-Decide` (GLiNERDecideTextClassifier)
   - `fastino/GLiNER2.5-multi-Decide` (GLiNERMultiDecideTextClassifier)
3. **Modelos diferidos para v0.2:**
   - `jaredpalmer/kev-0.8b`: debido a que requiere ejecución local en un proceso de loopback o motor especializado con adaptador sobre modelo base Qwen.
4. **Semántica de "Entrenamiento" Zero-Shot:**
   - En DashAI, el método `train(x_train, y_train, ...)` es obligatorio para inicializar el componente dentro de un experimento.
   - En este plugin, `train()` registrará el conjunto de etiquetas discretas (clases), configurará las preguntas fijas del router y preparará el backend sin alterar pesos neuronales, documentando con total honestidad la naturaleza zero-shot del modelo.
5. **No invasión del Core:** No se modificará el núcleo de DashAI para el lanzamiento v0.1; el plugin se registrará exclusivamente mediante los entry points de `pyproject.toml` bajo el grupo `dashai.plugins`.

## Consecuencias
- **Positivas:** El plugin es 100% instalable de forma desacoplada en cualquier instancia existente de DashAI. Los usuarios pueden evaluar modelos System One con las métricas estándar de clasificación (Accuracy, F1, LogLoss, ROCAUC).
- **Limitaciones v0.1:** Tareas multi-pregunta o respuestas mixtas (`score` continuo o `noul` booleano simultáneos) no son expuestas en la UI de clasificación de texto estándar y quedan disponibles mediante la API interna de contratos del plugin para v0.2.
